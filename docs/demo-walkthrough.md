# Demo Walkthrough

1. Start the stack with `make compose-up`.
2. Register CSV connectors from `examples/sample-connectors/csv-connectors.json`.
3. Run discovery jobs for the customer, HR, and finance CSV datasets.
4. Run classification to detect email, phone, passport, national ID, and card placeholders.
5. Review sample lineage in `examples/sample-lineage.json`.
6. Load sample policies from `examples/sample-policies.json`.
7. Review catalog, compliance, risk, and audit screens in the frontend.

The demo data is intentionally small and human-readable so governance behavior
can be reviewed without external systems.
