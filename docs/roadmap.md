# Roadmap

- Add persistent PostgreSQL repository implementations.
- Replace in-memory services with transactional storage and migrations.
- Add Kafka/Redpanda producers and consumers for asynchronous workers.

- Add production authentication and role-based access control.
- Add configurable detector packs and ML-assisted classification.
- Add CI workflows for backend, frontend, Docker, and security scans.
